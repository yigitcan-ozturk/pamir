# Blind Validation Protocol

The next maturity gate after the repository demonstrator is an authorized blind validation.

1. A system integrator or test authority supplies previously unseen, controlled data.
2. Acceptance criteria and permitted transformations are declared before execution.
3. PAMIR-CUAS processes the data without tuning to the expected answer.
4. The system emits causal findings, counterfactual results, provenance, and deterministic evidence hashes.
5. Results are reviewed against the predeclared criteria.

This protocol is for validation and incident reconstruction. It excludes targeting, engagement, guidance, interception, firing solutions, and effector control.
