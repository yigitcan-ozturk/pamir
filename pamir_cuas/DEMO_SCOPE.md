# Demonstrator Scope

PAMIR-CUAS demonstrator scope is vendor-neutral evidence-grade validation and bounded mission assurance for Counter-UAS sensor/C2 data paths.

Included: provenance, timing integrity, sensor disagreement, causal attribution, counterfactual replay, deterministic evidence reports, alert/isolation, bounded validation, recovery/rollback audit.

Excluded: weapon control, targeting, engagement guidance, terminal interception guidance, firing solutions, laser/HPM attack-parameter optimization, and direct physical defeat mechanisms.
