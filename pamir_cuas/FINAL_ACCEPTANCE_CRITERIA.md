# Final Acceptance Criteria

1. Full repository test suite passes on GitHub Actions.
2. End-to-end demonstrator test is present on the tested branch head.
3. Evidence serialization is deterministic and hashed.
4. Degraded source isolation is present in the resilience audit.
5. Recovery terminates in a bounded validated state.
6. Real-data provenance and controlled-injection provenance remain explicitly separated.
7. Scope limitations are documented.

Meeting these criteria establishes repository-level **demonstrator-ready** status only.
