# PAMIR Website

Investor-facing website deployment lane for `pamir.pamilanga.com`.

This directory/branch is intentionally isolated from the PAMIR v0.1 technical baseline.

## Deployment target
- Cloudflare Pages
- Custom domain: `pamir.pamilanga.com`
- Corporate parent: `https://www.pamilanga.com`
- Contact: `pamir@pamilanga.com`

## Public positioning
**Evidence-driven validation for autonomous systems.**

An engineering-led framework for turning simulation and real-world data into repeatable validation evidence.

## Truthfulness rules
- No fabricated traction, customers, pilots, benchmarks, flight hours or performance claims.
- Only verified PAMIR telemetry / ULog / benchmark evidence may be shown as real results.
- Funding language must be framed as a target until a round is formally opened.
- Current roadmap language: v0.1 stable baseline → v0.2 evidence calibration → external validation → pilot → productisation.

## Design direction
Cinematic, realistic, engineering-first. Black / graphite / off-white, controlled typography, real evidence panels, no cyberpunk UI.
